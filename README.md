# Mopie 插件仓库

这是 Mopie 的官方插件仓库，内容和本机正在使用的插件一致。

## 如何使用

1. 在 Mopie 中打开 **设置 → 插件管理**
2. 切换到 **插件市场** 标签页
3. 选择要安装的插件，点击 **安装** 按钮

安装包在 `dist/`。站点配置不在这个仓库，见 [mopie-sites](https://github.com/yl948/mopie-sites)。
